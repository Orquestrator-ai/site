Quantas linhas tem o roteiro?

Comando no arquivo de exemplo

wc -l roteiro.txt

Resultado no arquivo de exemplo: 3 linhas.

O comando conta as linhas; ele não avalia se as ideias são boas. Esta página mostra o exemplo e não executa nada no seu computador.
